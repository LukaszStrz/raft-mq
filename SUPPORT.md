# Support

## Getting Help

- **Bug reports & feature proposals:** Use the [GitHub Issue Forms](https://github.com/LukaszStrz/raft-mq/issues/new/choose).
- **Security vulnerabilities:** Do **not** open a public issue. Report vulnerabilities privately via [GitHub Private Vulnerability Reporting](https://github.com/LukaszStrz/raft-mq/security/advisories/new) as described in [SECURITY.md](SECURITY.md).
