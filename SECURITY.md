# Security Policy

## Supported Versions

`raft-mq` is currently in pre-release development. Security fixes are applied to the latest state of the `main` branch and, once releases begin, to the latest released version line.

| Version | Supported |
|---|---|
| `main` (unreleased) | :white_check_mark: |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues, discussions, or pull requests.**

Instead, please report them privately using [GitHub Private Vulnerability Reporting](https://github.com/LukaszStrz/raft-mq/security/advisories/new).

When submitting a report, please include:

- A clear description of the issue and its potential impact
- Affected commit SHA, tag, or NuGet package version
- Minimal steps or proof-of-concept code to reproduce the issue
- Any suggested mitigation or fix, if known

## Response Expectations

As an open-source project maintained by a solo maintainer, reports are handled on a best-effort basis:

- **Initial acknowledgment:** within 7 days
- **Triage & status update:** within 14 days
- **Coordinated disclosure:** once a fix is released (or a mitigation is agreed upon), the advisory will be published with credit to the reporter unless anonymity is requested
